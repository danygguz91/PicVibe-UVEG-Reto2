# PicVibe

Aplicación web educativa desarrollada con HTML,
CSS y JavaScript.

## Funcionalidades
- Visualización de imágenes
- Búsqueda de publicaciones
- Filtros por categorías
- Selección de favoritos

## Organización
- css/: estilos
- js/: funcionalidades
- img/: recursos gráficos

## Propósito
Demostrar el empaquetado, versionamiento
y despliegue de aplicaciones web.
